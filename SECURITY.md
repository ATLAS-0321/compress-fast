# Security

compress-fast listens on 127.0.0.1 by default and sees everything Hermes sends to your model,
including session content. Shadow mode stores prompts and summaries on disk (0700/0600).

Please report security problems privately through
[GitHub's private vulnerability reporting](https://github.com/ATLAS-0321/compress-fast/security/advisories/new),
not in a public issue.
